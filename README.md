# Mutasd! – Képes activity gyerekeknek

Magyar nyelvű, mobilon és számítógépen használható egyoldalas játék. 83 kártya: 24 állat, 13 foglalkozás (köztük balerina), 14 jármű és 32 hétköznapi tárgy, képes kártyák, egykattintásos húzás, Állatok / Foglalkozások / Járművek / Hétköznapi tárgyak / Minden témaválasztó. A pakli csak akkor keveredik újra, ha minden kártyát kihúztatok. A kártyára kattintva vagy a szóközzel is lehet húzni.

## Használat

Nyisd meg az `index.html` fájlt egy böngészőben. Nincs telepítés, fordítás, fiók vagy külső szolgáltatás. A képek az `assets` mappában vannak, az oldal letöltés után internet nélkül is megnyitható.

## GitHub Pages

1. Töltsd fel az `index.html`, `style.css`, `app.js`, `.nojekyll` fájlokat és a teljes `assets` mappát egy GitHub repository gyökerébe.
2. A repository **Settings → Pages** részén válaszd a **Deploy from a branch** lehetőséget.
3. Állítsd be a **main** ágat és a **/ (root)** mappát, majd mentsd.
4. A GitHub az elkészülés után ugyanitt megjeleníti a publikus címet.

Az alkalmazás relatív elérési utakat használ, ezért repository alatti GitHub Pages-címen is működik.
